# 8. 화면 구성과 UX 라이팅

목표: 7번까지 만든 화면의 구성과 문구를 `docs/21_UX_문구.md` v0.8에 맞춘다. 디자인을 입히기 전에 무엇이 어디에 있고 무슨 문구를 쓰는지부터 고정한다.

문구가 흔들리면 디자인이 흔들린다. 글자 수가 달라지면 줄 수가 달라지고, 줄 수가 달라지면 카드 높이와 여백이 전부 다시 계산된다. 그래서 디자인보다 이 단계를 먼저 한다.

---

## 8-1. 기준 문서

| 문서 | 무엇을 가져오나 |
| --- | --- |
| `docs/21_UX_문구.md` v0.8 | 섹션 순서, 배치도, 섹션별 문구 전체 |
| `docs/11_seed.yaml` | 화면 구성 제약, 수락 기준 |
| `PRODUCT.md` | 사용자상, 용어, UX 라이팅 원칙 |

셋이 다르면 **문구는 21번 배치도**를 따른다. 배치도에 적힌 사용자 문구는 이미 결정된 사항이다. 어색해 보여도 임의로 고치지 않고, 고칠 이유가 있으면 먼저 묻는다.

---

## 8-2. 화면 구성 확정

화면은 둘이다.

```
QR 스캔 ──▶ /verify (기관코드 확인) ──▶ /welcome (랜딩)
```

`/welcome`의 섹션 순서는 다음과 같다. `src/sections/registry.ts` 배열 순서와 이 표가 일치해야 한다.

| 번호 | 섹션 id | 역할 |
| --- | --- | --- |
| Header | — | 로고 |
| 01 | `hero` | 편지 도착, 애니메이션 |
| 02 | `intro` | 위둘 소개, 기능 카드 4개 |
| 03 | `anonymity` | 익명성, 카드 3개 |
| 04 | `account` | 계정 발급, 계정 이미지 저장 |
| 05 | `process` | 앱 이용 흐름 5단계 |
| 06 | `install` | 앱 설치, 사용자 매뉴얼 다운로드 |
| 07 | `faq` | 자주 묻는 질문 |
| Footer | — | 운영사 정보, 고객센터 |

확인할 것.

- 매뉴얼 다운로드 버튼은 `install` 한 곳에만 둔다.
- 만료 전용 화면과 재발급 버튼은 두지 않는다. 계정은 화면 state로만 들고 있고, 새로고침하면 발급 전 상태로 돌아간다.
- 긴급 연락처 섹션은 없다.

---

## 8-3. 문구가 사는 곳

문구는 컴포넌트 안에 직접 쓰지 않는다. 두 곳에만 둔다.

| 위치 | 담는 것 |
| --- | --- |
| `src/sections/<섹션 id>/content.ts` | 그 섹션에서만 쓰는 문구 |
| `src/content/common.ts` | 여러 곳에서 쓰는 문구, 푸터, 공통 라벨 |

이렇게 두면 문구만 고칠 때 컴포넌트를 건드리지 않아도 되고, 21번 문서와 한 줄씩 맞춰 보기도 쉽다.

섹션 제목은 **라벨·제목·설명** 세 줄 구조다. 산타 토익 랜딩을 참고해 v0.7에서 정했다.

```ts
export const processContent = {
  label: '프로세스',
  title: '위둘 EAP, 다섯 단계로 사용해요',
  // ...
} as const;
```

## 8-4. 문체 원칙

| 항목 | 규칙 |
| --- | --- |
| 어미 | 해요체로 통일한다 |
| 설명 | 동작 원리를 설명하지 않는다. 버튼만으로 뜻이 통하면 설명 문구를 두지 않는다 |
| 불가 안내 | 안 되는 일은 짧은 이유를 붙여 완곡하게 쓴다 |
| 용어 | 기관코드, 계정, 기관, 운영사, 자가진단으로 고정한다 |
| 약속 | 계약 5개 조항의 뜻을 넘어서는 약속을 하지 않는다 |

`FAQ 4번` 답변이 좋은 예다. "복구 불가"라고 끊지 않고, 이유와 대안을 함께 준다.

> 비식별 계정이라 다시 찾아 드리기 어려운 점 양해 부탁드립니다. 페이지를 새로고침하시면 새 계정을 발급받으실 수 있어요. 다만 이전 기록은 이어지지 않아요.

## 8-5. 상태별 문구

정상 화면만 있는 게 아니다. 아래 상태의 문구가 모두 있어야 9번 디자인 단계에서 화면을 그릴 수 있다.

| 화면 | 상태 | 있어야 할 문구 |
| --- | --- | --- |
| `/verify` | 기본 / 확인 중 / 코드 오류 / 연결 오류 | 입력 안내, 버튼 라벨, 오류 문구 |
| `account` | 발급 전 / 발급 중 / 발급 후 / 오류 | 버튼 라벨, 만료 시각 안내, 저장 안내, 재시도 |
| `install` | 기본 | QR 설명, 스토어 버튼, 매뉴얼 버튼 |
| `faq` | 접힘 / 펼침 | 질문 7개와 답변 |

21번 문서 4장의 표에 상태별 문구가 이미 정리되어 있다. 빠진 상태가 있으면 지어내지 말고 미결로 올린다.
