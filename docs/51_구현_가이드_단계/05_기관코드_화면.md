# 5. 기관코드 확인 화면 (`/verify`)

목표: QR 주소로 들어오면 기관코드가 채워지고, 6글자가 되면 확인해 `/welcome`으로 넘어가는 화면을 만든다. 기획 문서 4장 ①.

---

## 5-1. 동작 정리

| 상황                             | 동작                                                  |
| -------------------------------- | ----------------------------------------------------- |
| `/verify?GGCF26=A1B2C3`로 들어옴 | 입력칸에 `A1B2C3`이 채워지고 바로 확인                |
| 확인 성공                        | 기관코드 저장 → `/welcome`으로 이동                   |
| 기관코드 오류                    | 입력칸 비우기 + 「기관코드를 다시 확인해 주세요」     |
| 그 밖의 오류                     | 입력값 유지 + 「잠시 후 다시 시도해 주세요」          |
| 수기 입력                        | 영문·숫자만, 대문자로 바꿔 보여 줌. 6글자가 되면 확인 |
| 확인하는 동안                    | 입력칸을 읽기 전용으로 바꿔 중복 확인을 막음          |

## 5-3. 입력 폼 컴포넌트

`src/features/org-code/OrgCodeForm.tsx`

```tsx
'use client';

import { useRouter, useSearchParams } from 'next/navigation';
import { useEffect, useRef, useState } from 'react';
import { commonContent } from '@/content/common';
import { useFlow } from '@/features/flow/FlowProvider';
import { toErrorKind } from '@/lib/api/errors';
import { verifyOrgCode } from '@/lib/api/org';
import { orgCodeContent } from './content';

const ORG_CODE_LENGTH = 6;
const QR_PARAM_KEY = 'GGCF26'; // QR 주소의 파라미터 키

type Status = 'idle' | 'checking' | 'invalid' | 'error';
type VerifyResult = 'ok' | 'invalid' | 'error';

/** 영문·숫자만 남기고 대문자로 바꾸고 6글자까지 자른다 */
function normalizeOrgCode(value: string): string {
  return value
    .replace(/[^a-zA-Z0-9]/g, '')
    .toUpperCase()
    .slice(0, ORG_CODE_LENGTH);
}

/** 기관코드 API 검증 결과 반환 */
async function checkOrgCode(orgCode: string): Promise<VerifyResult> {
  try {
    await verifyOrgCode(orgCode);
    return 'ok';
  } catch (error) {
    return toErrorKind(error) === 'invalidOrgCode' ? 'invalid' : 'error';
  }
}

export function OrgCodeForm() {
  const router = useRouter();
  const searchParams = useSearchParams();
  const { confirmOrgCode } = useFlow();

  const initialOrgCode = normalizeOrgCode(searchParams.get(QR_PARAM_KEY) ?? '');
  const hasFullInitialCode = initialOrgCode.length === ORG_CODE_LENGTH;

  const [value, setValue] = useState(initialOrgCode);
  const [status, setStatus] = useState<Status>(hasFullInitialCode ? 'checking' : 'idle');
  const autoCheckedRef = useRef(false);

  /** 검증 결과에 따라 후속 라우팅 처리 */
  function applyResult(orgCode: string, result: VerifyResult) {
    if (result === 'ok') {
      confirmOrgCode(orgCode);
      router.replace('/welcome');
      return;
    }

    if (result === 'invalid') {
      setValue('');
    }
    setStatus(result);
  }

  // QR 진입 시 6자리 코드 유효성 충족할 경우 최초 1회 자동 검증 실행
  useEffect(() => {
    if (autoCheckedRef.current) return;
    autoCheckedRef.current = true;

    if (!hasFullInitialCode) return;

    // 상태 변경은 서버 응답이 온 뒤 .then 콜백에서 한다
    void checkOrgCode(initialOrgCode).then((result) => applyResult(initialOrgCode, result));

    // 마운트 시점 최초 1회만 수행되도록 의존성 배열 비움
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  function handleChange(event: React.ChangeEvent<HTMLInputElement>) {
    if (status === 'checking') return;

    const nextValue = normalizeOrgCode(event.target.value);
    setValue(nextValue);

    if (nextValue.length === ORG_CODE_LENGTH) {
      setStatus('checking');
      void checkOrgCode(nextValue).then((result) => applyResult(nextValue, result));
    } else {
      setStatus('idle');
    }
  }

  const message =
    status === 'invalid'
      ? commonContent.errors.invalidOrgCode
      : status === 'error'
        ? commonContent.errors.network
        : '';

  return (
    <div className="flex w-full flex-col gap-3">
      <label htmlFor="org-code" className="text-title font-bold">
        {orgCodeContent.label}
      </label>

      <input
        id="org-code"
        name="orgCode"
        value={value}
        onChange={handleChange}
        readOnly={status === 'checking'}
        placeholder={orgCodeContent.placeholder}
        inputMode="text"
        autoCapitalize="characters"
        autoComplete="off"
        autoCorrect="off"
        spellCheck={false}
        aria-invalid={status === 'invalid'}
        aria-describedby="org-code-message"
        aria-busy={status === 'checking'}
        className="min-h-touch w-full rounded-xl border-2 border-line px-4 text-center font-mono text-title tracking-[0.3em] uppercase focus:border-brand focus:outline-none aria-[invalid=true]:border-danger"
      />

      <p id="org-code-message" aria-live="polite" className="min-h-[1.7em] text-danger">
        {message}
      </p>
    </div>
  );
}
```

### 코드 읽기

**입력값 다듬기**

- `normalizeOrgCode`: 붙여 넣은 값에 공백이나 `-`가 섞여도 영문·숫자만 남긴다
- `maxLength`를 쓰지 않았다. `maxLength`는 붙여 넣을 때 **다듬기 전에** 잘라서 `A1-B2-C3`이 `A1-B2-`가 된다. 대신 다듬은 뒤 6글자로 자른다

**처음 상태**

- `useSearchParams().get('GGCF26')`: 주소의 `?GGCF26=...` 값을 읽는다. 없으면 `null`
- QR로 6글자가 들어오면 처음부터 `status`를 `'checking'`으로 둔다. 확인하는 동안 입력칸이 잠긴다

**자동 확인 (`useEffect`)**

- 화면이 뜬 뒤 한 번 실행된다
- `autoCheckedRef`: 개발 모드(StrictMode)에서는 `useEffect`가 두 번 실행된다. 두 번 확인하지 않도록 막는다
- `eslint-disable-next-line`: 「의존성 배열에 값이 빠졌다」는 경고를 끈다. 처음 한 번만 실행하려는 의도라서 끈다

**확인 결과 (`checkOrgCode`, `applyResult`)**

- `checkOrgCode`: 서버 검증 후 `'ok'`, `'invalid'`, `'error'` 중 하나를 반환하며, 상태는 변경하지 않는다.
- `applyResult`: 검증 결과에 따라 페이지를 이동하거나 상태를 변경한다.
- **성공**: `confirmOrgCode`에 값을 저장하고 `router.replace('/welcome')`로 이동한다. `replace`를 사용하므로 뒤로 가기로 이 화면에 돌아올 수 없다.
- **기관코드 오류**: 입력칸을 비운다. 다시 입력하면 `handleChange`가 `status`를 `'idle'`로 변경해 오류 문구가 사라진다.
- **기타 오류**: 입력값을 유지한다. 한 글자를 지웠다 다시 입력하면 재시도할 수 있다.
- 성공 시 `status`는 `'checking'` 상태를 유지한다. 페이지를 이동하는 동안 입력칸을 잠금 상태로 두기 위함이다.

**접근성**

- `<label htmlFor="org-code">`와 `<input id="org-code">`를 연결해 화면 낭독기가 「기관코드, 입력칸」으로 읽는다
- `aria-live="polite"`: 오류 문구가 나타나면 화면 낭독기가 읽어 준다
- `readOnly`를 썼다. `disabled`는 휴대전화에서 키보드가 닫히고 초점이 사라진다

**휴대전화 키보드**

- `autoCapitalize="characters"`: 대문자 키보드로 시작한다
- `autoCorrect="off"`, `spellCheck={false}`: 자동 수정이 기관코드를 바꾸지 않게 한다

**클래스**

- `aria-[invalid=true]:border-danger`: `aria-invalid`가 `true`일 때만 빨간 테두리
- `tracking-[0.3em]`: 글자 간격을 넓혀 한 글자씩 읽기 쉽게 한다
- `min-h-[1.7em]`: 문구가 없을 때도 자리를 잡아 두어, 오류가 나타날 때 화면이 밀리지 않게 한다

## 5-4. 페이지

`src/app/verify/page.tsx` (4번 문서의 임시 버튼을 지우고 교체)

```tsx
import { Suspense } from 'react';
import { OrgCodeForm } from '@/features/org-code/OrgCodeForm';

export default function VerifyPage() {
  return (
    <main className="mx-auto flex min-h-dvh w-full max-w-md flex-col justify-center px-5">
      <Suspense fallback={null}>
        <OrgCodeForm />
      </Suspense>
    </main>
  );
}
```

### 왜 Suspense로 감싸는가

`useSearchParams`는 주소의 `?` 뒤를 읽는다. 이 값은 빌드할 때는 알 수 없고 이용자가 접속할 때 정해진다. Next.js는 `useSearchParams`를 쓰는 컴포넌트를 `<Suspense>`로 감싸라고 요구한다. 감싸지 않으면 `pnpm build`에서 「useSearchParams() should be wrapped in a suspense boundary」 오류가 난다.

- 이 파일은 서버 컴포넌트다(`'use client'` 없음). `OrgCodeForm`만 클라이언트 컴포넌트다
- `min-h-dvh`: 휴대전화 주소창 높이를 뺀 실제 화면 높이만큼 채워 가운데 정렬한다

## 5-5. 확인

`.env.local`의 `NEXT_PUBLIC_MOCK_VALID_ORG_CODE=A1B2C3` 기준이다. Session Storage를 비우려면 탭을 닫고 새 탭을 연다.

| #   | 할 일                                       | 기대 결과                                       |
| --- | ------------------------------------------- | ----------------------------------------------- |
| 1   | `/verify?GGCF26=A1B2C3`                     | 입력칸에 `A1B2C3`, 잠시 뒤 `/welcome`           |
| 2   | `/verify?GGCF26=a1b2c3`                     | 대문자로 바뀌어 확인, `/welcome`                |
| 3   | `/verify?GGCF26=ZZZZZZ`                     | 입력칸이 비고 「기관코드를 다시 확인해 주세요」 |
| 4   | 3 다음 한 글자 입력                         | 오류 문구가 사라짐                              |
| 5   | `/verify` 에서 `a1b2c3` 입력                | 6번째 글자에서 확인, `/welcome`                 |
| 6   | `/verify`에서 `A1-B2-C3` 붙여 넣기          | `A1B2C3`으로 다듬어져 확인                      |
| 7   | `/verify?GGCF26=ERR500`                     | 입력값 유지, 「잠시 후 다시 시도해 주세요」     |
| 8   | `/verify?GGCF26=A1B`                        | 자동 확인 안 함, 나머지 입력 대기               |
| 9   | 1 다음 뒤로 가기                            | `/verify`로 돌아오지 않음                       |
| 10  | 휴대전화 크기(개발자 도구 기기 모드)로 입력 | 입력칸이 화면 너비에 맞음                       |
