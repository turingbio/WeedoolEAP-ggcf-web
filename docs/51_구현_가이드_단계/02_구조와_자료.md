# 2. 구조와 자료

목표: 폴더를 만들고, 임시 자료와 디자인 토큰, 공통 버튼을 준비한다.

---

## 2-1. 폴더 만들기

```bash
mkdir -p src/app/verify src/app/welcome
mkdir -p src/components/ui
mkdir -p src/config src/content src/types
mkdir -p src/features/flow src/features/org-code src/features/account
mkdir -p src/lib/api/mock
mkdir -p src/sections/intro src/sections/anonymity src/sections/manual
mkdir -p src/sections/account src/sections/credential-image src/sections/install
mkdir -p public/brand public/manual public/store
```

### 각 폴더의 역할

| 폴더             | 들어가는 것                | 규칙                                                   |
| ---------------- | -------------------------- | ------------------------------------------------------ |
| `src/app`        | 주소가 되는 페이지         | 페이지 파일에는 조립만 하고 로직을 적게 둔다           |
| `src/sections`   | 랜딩 페이지 섹션           | 섹션 하나 = 폴더 하나. 섹션끼리 서로 import하지 않는다 |
| `src/components` | 여러 곳에서 쓰는 화면 조각 | 특정 섹션에만 쓰이면 그 섹션 폴더에 둔다               |
| `src/features`   | 화면 기능과 상태           | 흐름 상태, 기관코드 입력, 만료 판단                    |
| `src/lib`        | 화면과 무관한 함수         | API 호출, 시각 형식                                    |
| `src/content`    | 섹션 밖의 공통 문구        | 오류 문구, 푸터                                        |
| `src/config`     | 나중에 바뀌는 주소·경로    | 스토어 URL, 파일 경로                                  |
| `src/types`      | 데이터 타입                | API 계약 문서의 필드 이름 그대로                       |

기존 `public/`에 Next.js 기본 SVG 파일(`next.svg`, `vercel.svg` 등)이 있으면 지운다.

## 2-2. 임시 자료

진짜 자료가 오기 전까지 쓸 파일이다. 경로만 맞으면 나중에 파일만 바꾸면 된다.

### 이미지

`placehold.co`에서 임시 PNG를 받는다.

```bash
curl -o public/brand/intro.png "https://placehold.co/640x480/png?text=WeeDool"
curl -o public/store/qr-ios.png "https://placehold.co/300x300/png?text=iOS+QR"
curl -o public/store/qr-android.png "https://placehold.co/300x300/png?text=Android+QR"
```

인터넷이 막혀 있으면 아무 PNG 파일을 같은 이름으로 넣는다.

### 매뉴얼 PDF

아무 PDF 한 쪽을 `public/manual/weedool-manual.pdf` 이름으로 넣는다. 없으면 메모장에 「매뉴얼 준비 중」을 적고 「PDF로 인쇄」로 저장한다.

**확인:** `pnpm dev`를 켜고 아래 주소가 열린다.

- `http://localhost:3000/brand/intro.png`
- `http://localhost:3000/store/qr-ios.png`
- `http://localhost:3000/manual/weedool-manual.pdf`

## 2-3. 경로 설정 파일

진짜 자료가 오면 **이 파일만** 고친다.

`src/config/links.ts`

```ts
// 스토어 URL과 QR 이미지는 나중에 받는다. 받기 전까지 '#'과 임시 이미지를 쓴다.
export const links = {
  manual: {
    href: '/manual/weedool-manual.pdf',
    fileName: 'weedool-manual.pdf',
  },
  appStore: {
    href: '#',
    qrImage: '/store/qr-ios.png',
  },
  googlePlay: {
    href: '#',
    qrImage: '/store/qr-android.png',
  },
  introImage: '/brand/intro.png',
} as const;
```

- `as const`: 값이 바뀌지 않는 설정이라고 TypeScript에 알려 준다. 오타를 잡아 준다

## 2-4. 디자인 토큰 (globals.css)

색·글자 크기·간격 같은 디자인 값을 **한 곳에 이름으로** 정한다. 컴포넌트에서는 `#2563eb` 같은 값을 직접 쓰지 않고 `bg-brand` 같은 이름만 쓴다. 디자인 시스템이 오면 이 파일의 값만 바꾼다.

`src/app/globals.css` 내용을 **전부 지우고** 아래로 바꾼다.

```css
@import 'tailwindcss';

/*
 * 디자인 토큰
 * 지금 값은 임시다. 디자인 시스템을 받으면 값만 바꾼다. 이름은 유지한다.
 */
@theme {
  /* 색 */
  --color-brand: #2563eb;
  --color-brand-strong: #1d4ed8;
  --color-ink: #111827;
  --color-muted: #4b5563;
  --color-line: #e5e7eb;
  --color-surface: #f9fafb;
  --color-danger: #b91c1c;

  /* 글꼴 */
  --font-sans:
    var(--font-app), system-ui, -apple-system, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif;

  /* 글자 크기 (접근성 기준: 본문 16px 이상, 버튼 20px 이상) */
  --text-body: 1.125rem;
  --text-body--line-height: 1.7;
  --text-button: 1.25rem;
  --text-title: 1.75rem;
  --text-title--line-height: 1.35;

  /* 터치 영역 (48px 이상) */
  --spacing-touch: 3rem;
}

html {
  -webkit-text-size-adjust: 100%;
}

body {
  word-break: keep-all;
}
```

### 이 파일이 만드는 클래스

`@theme`에 `--종류-이름`으로 적으면 Tailwind가 클래스를 만들어 준다.

| 토큰              | 쓸 수 있는 클래스 예                     |
| ----------------- | ---------------------------------------- |
| `--color-brand`   | `bg-brand`, `text-brand`, `border-brand` |
| `--color-danger`  | `text-danger`                            |
| `--text-body`     | `text-body` (글자 크기 + 줄 높이)        |
| `--text-title`    | `text-title`                             |
| `--spacing-touch` | `min-h-touch`, `h-touch`, `min-w-touch`  |
| `--font-sans`     | `font-sans`                              |

- `word-break: keep-all`: 한국어 단어가 중간에서 끊기지 않게 한다
- `--font-app`은 아래 글꼴 단계에서 채운다. 비어 있으면 뒤의 시스템 글꼴을 쓴다

**확인:** `pnpm dev`가 오류 없이 켜진다.

## 2-5. 글꼴

### 디자인 시스템 글꼴을 받기 전

아무것도 하지 않는다. `--font-sans`의 시스템 글꼴(iPhone은 Apple SD Gothic Neo, Windows는 맑은 고딕)이 쓰인다.

### 글꼴 파일을 받은 뒤

1. 글꼴 파일을 `src/app/fonts/`에 넣는다 (예: `Pretendard-Regular.woff2`, `Pretendard-Bold.woff2`)
2. `layout.tsx`에서 `next/font/local`로 불러오고 `variable`로 CSS 변수를 만든다

```tsx
import localFont from 'next/font/local';

const appFont = localFont({
  src: [
    { path: './fonts/Pretendard-Regular.woff2', weight: '400' },
    { path: './fonts/Pretendard-Bold.woff2', weight: '700' },
  ],
  variable: '--font-app',
  display: 'swap',
});

// <html lang="ko" className={appFont.variable}>
```

- `variable: '--font-app'`: `globals.css`의 `var(--font-app)`와 이름이 같아야 한다

## 2-6. 공통 버튼

모든 섹션이 같은 모양의 버튼을 쓰도록 한 파일에 만든다. 디자인 시스템이 오면 이 파일만 고친다.

버튼은 두 종류다.

- `Button`: 누르면 코드가 실행된다 (계정 받기)
- `ButtonLink`: 누르면 주소로 간다 (매뉴얼 다운로드, 스토어)

`src/components/ui/Button.tsx`

```tsx
import type { ComponentProps } from 'react';

type Variant = 'primary' | 'secondary';

const baseClass =
  'inline-flex min-h-touch w-full items-center justify-center rounded-xl px-6 text-button font-bold ' +
  'focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-brand ' +
  'disabled:cursor-not-allowed disabled:opacity-50';

const variantClass: Record<Variant, string> = {
  primary: 'bg-brand text-white active:bg-brand-strong',
  secondary: 'border-2 border-brand bg-white text-brand',
};

function buttonClassName(variant: Variant, className?: string) {
  return [baseClass, variantClass[variant], className].filter(Boolean).join(' ');
}

type ButtonProps = ComponentProps<'button'> & { variant?: Variant };

export function Button({ variant = 'primary', className, type = 'button', ...props }: ButtonProps) {
  return <button type={type} className={buttonClassName(variant, className)} {...props} />;
}

type ButtonLinkProps = ComponentProps<'a'> & { variant?: Variant };

export function ButtonLink({ variant = 'primary', className, ...props }: ButtonLinkProps) {
  return <a className={buttonClassName(variant, className)} {...props} />;
}
```

### 코드 읽기

- `ComponentProps<'button'>`: `<button>`이 받을 수 있는 모든 속성(`onClick`, `disabled` 등)을 그대로 받겠다는 뜻
- `...props`: 받은 나머지 속성을 그대로 넘긴다
- `type = 'button'`: `<button>`의 기본값은 `submit`이라 폼 안에서 의도치 않게 제출된다. 기본값을 `button`으로 바꾼다
- `min-h-touch`: 2-4에서 만든 48px 토큰
- `focus-visible:`: 키보드로 이동했을 때만 테두리를 보여 준다
- 이 파일에는 `'use client';`가 없다. 상태나 이벤트를 직접 쓰지 않기 때문이다. `onClick`은 이 버튼을 쓰는 쪽(클라이언트 컴포넌트)에서 넘긴다

## 2-7. 빈 페이지로 빌드 확인

주소 세 개를 임시 내용으로 만든다. 4번 문서에서 제대로 채운다.

`src/app/page.tsx` (기존 내용 전부 교체)

```tsx
export default function RootPage() {
  return null;
}
```

`src/app/verify/page.tsx`

```tsx
export default function VerifyPage() {
  return <main>verify</main>;
}
```

`src/app/welcome/page.tsx`

```tsx
export default function WelcomePage() {
  return <main>welcome</main>;
}
```

`src/app/layout.tsx` (기존 내용 전부 교체)

```tsx
import type { Metadata } from 'next';
import './globals.css';

export const metadata: Metadata = {
  title: '위둘 EAP',
  description: '위둘 EAP 안내',
};

export default function RootLayout({ children }: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="ko">
      <body className="bg-white font-sans text-body text-ink antialiased">{children}</body>
    </html>
  );
}
```

- `metadata`: 브라우저 탭 제목. 서버 컴포넌트에서만 쓸 수 있다
- `lang="ko"`: 화면 낭독기가 한국어로 읽는다

```bash
pnpm build
```

- `pnpm build`가 성공한다
- `pnpm dev` 후 `/verify`에 「verify」, `/welcome`에 「welcome」이 보인다
