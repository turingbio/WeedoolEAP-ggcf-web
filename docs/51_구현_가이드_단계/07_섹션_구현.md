## 7-4. 만료 판단 훅

⑤ 계정 발급 섹션에서 「지금 만료됐는가」를 알려 주는 훅이다.

### 어떻게 동작하는가

- `expiresAt`까지 남은 시간만큼 **타이머를 한 번** 건다. 시간이 되면 다시 판단한다
- 휴대전화 화면이 꺼졌다 켜지면 타이머가 늦게 울릴 수 있다. 화면이 다시 보일 때(`visibilitychange`)도 판단한다
- 1초마다 도는 타이머는 쓰지 않는다. 남은 시간을 화면에 보여 주지 않기 때문이다

`src/features/account/useIsExpired.ts`

```ts
'use client';

import { useCallback, useSyncExternalStore } from 'react';

/** expiresAt이 지났으면 true. 시간이 되거나 화면이 다시 보일 때 다시 판단한다 */
export function useIsExpired(expiresAt: string | null): boolean {
  const subscribe = useCallback(
    (onChange: () => void) => {
      if (!expiresAt) {
        return () => {};
      }

      const remainingMs = new Date(expiresAt).getTime() - Date.now();
      const timer = window.setTimeout(onChange, Math.max(remainingMs, 0) + 100);
      document.addEventListener('visibilitychange', onChange);

      return () => {
        window.clearTimeout(timer);
        document.removeEventListener('visibilitychange', onChange);
      };
    },
    [expiresAt],
  );

  const getSnapshot = () => expiresAt !== null && Date.now() >= new Date(expiresAt).getTime();

  return useSyncExternalStore(subscribe, getSnapshot, () => false);
}
```

### 코드 읽기

- `useSyncExternalStore(구독, 현재값, 서버값)`: 4번 문서와 같은 방식이다. 이번에는 「시계」가 React 밖의 값이다
- `subscribe`: React가 부른다. 타이머와 이벤트를 걸고, 치우는 함수를 돌려준다. `onChange`를 부르면 React가 `getSnapshot`을 다시 불러 값을 확인한다
- `+ 100`: 타이머가 정확히 그 순간보다 조금 빨리 울려도 만료로 판단되게 여유를 준다
- `useCallback(..., [expiresAt])`: `expiresAt`이 바뀔 때(재발급)만 구독을 새로 건다
- 서버값 `() => false`: 서버에서는 만료가 아닌 것으로 본다

## 7-5. ⑤ 계정 발급

### 상태 정리

| 상태 | 조건 | 화면 |
| --- | --- | --- |
| 발급 전 | 계정 없음 | 「계정 받기」 |

### 컴포넌트

`src/sections/account/AccountSection.tsx`

```tsx
'use client';

import { useState } from 'react';
import { SectionWrapper } from '@/components/SectionWrapper';
import { Button } from '@/components/ui/Button';
import { commonContent } from '@/content/common';
import { useIsExpired } from '@/features/account/useIsExpired';
import { useFlow } from '@/features/flow/FlowProvider';
import { issueAccount } from '@/lib/api/accounts';
import { formatTime } from '@/lib/format';
import type { SectionProps } from '../types';
import { accountContent } from './content';

type RequestStatus = 'idle' | 'loading' | 'error';

export function AccountSection({ id }: SectionProps) {
  const { orgCode, account, setAccount } = useFlow();
  const [requestStatus, setRequestStatus] = useState<RequestStatus>('idle');
  const isExpired = useIsExpired(account?.expiresAt ?? null);

  const isLoading = requestStatus === 'loading';

  async function handleIssue() {
    if (!orgCode || isLoading) return;

    setRequestStatus('loading');
    try {
      const nextAccount = await issueAccount(orgCode);
      setAccount(nextAccount);
      setRequestStatus('idle');
    } catch {
      setRequestStatus('error');
    }
  }

  const showButton = !account || isExpired;
  const buttonLabel = isLoading
    ? accountContent.loadingButton
    : account
      ? accountContent.reissueButton
      : accountContent.issueButton;

  return (
    <SectionWrapper id={id}>
      {account && (
        <div className={isExpired ? 'opacity-40' : undefined}>
          <dl className="grid grid-cols-[auto_1fr] items-center gap-x-4 gap-y-3 rounded-2xl border-2 border-line p-5">
            <dt className="text-muted">{accountContent.idLabel}</dt>
            <dd className="font-mono text-title tracking-wider select-all">{account.accountId}</dd>
            <dt className="text-muted">{accountContent.passwordLabel}</dt>
            <dd className="font-mono text-title tracking-wider select-all">
              {account.accountPassword}
            </dd>
          </dl>
        </div>
      )}

      <div aria-live="polite" className="mt-4">
        {account && !isExpired && (
          <p className="font-bold">{accountContent.loginUntil(formatTime(account.expiresAt))}</p>
        )}
        {account && isExpired && <p className="font-bold text-danger">{accountContent.expired}</p>}
        {requestStatus === 'error' && <p className="text-danger">{commonContent.errors.network}</p>}
      </div>

      {showButton && (
        <Button onClick={handleIssue} disabled={isLoading} className="mt-6">
          {buttonLabel}
        </Button>
      )}
    </SectionWrapper>
  );
}
```

### 코드 읽기

**상태**
- `account`: 흐름 상태(Context)에 있다. ⑥ PNG 섹션도 같은 값을 읽는다
- `requestStatus`: 이 섹션 안에서만 쓰는 요청 상태라 `useState`에 둔다
- `account?.expiresAt ?? null`: 계정이 없으면 `null`을 넘긴다

**발급·재발급**
- 발급과 재발급은 같은 `handleIssue`다. API 계약 4장대로 같은 API를 다시 부른다. 이전 계정 정보는 보내지 않는다
- `if (!orgCode || isLoading) return;`: 두 번 연달아 눌러도 한 번만 요청한다
- 성공하면 `setAccount`로 새 계정을 넣는다. `expiresAt`이 바뀌므로 `useIsExpired`가 새 타이머를 건다

**화면**
- `showButton`: 계정이 없거나 만료됐을 때만 버튼을 보인다
- `<dl>`, `<dt>`, `<dd>`: 「이름–값」 목록을 뜻하는 HTML. 화면 낭독기가 「아이디, wd7k3m9p」로 읽는다
- `grid-cols-[auto_1fr]`: 왼쪽 열은 글자 너비만큼, 오른쪽 열은 나머지
- `font-mono tracking-wider`: 고정폭 글꼴과 넓은 간격으로 옮겨 적기 쉽게 한다
- `select-all`: 한 번 누르면 값 전체가 선택된다
- `aria-live="polite"`: 만료 문구·오류 문구가 나타나면 화면 낭독기가 읽는다

## 7-6. ⑥ 계정 정보 저장 (PNG)

### 어떻게 동작하는가

1. 계정이 발급되면 이 섹션이 나타나고 계정 카드(`CredentialCard`)를 그린다. 이 카드가 곧 미리보기다
2. 카드가 그려지면 **자동으로** `html-to-image`가 카드 요소를 PNG로 바꿔 내려받는다
3. 재발급하면 새 계정 카드로 다시 자동으로 내려받는다
4. 「이미지로 저장」 버튼을 누르면 같은 방식으로 다시 내려받는다

### 저장 위치

웹사이트는 파일을 저장할 폴더를 정할 수 없다. `<a download>`로 내려받으면 **브라우저의 기본 다운로드 폴더**에 저장된다. 따로 설정할 코드는 없다.

| 환경 | 저장되는 곳 |
| --- | --- |
| Windows Chrome·Edge | `다운로드` 폴더 |
| Android Chrome | `Download` 폴더 (파일 앱 → 다운로드) |
| iPhone Safari | 파일 앱 → `다운로드` 폴더. 확인 창이 뜨면 「다운로드」를 누른다 |

- 브라우저에서 「다운로드 전에 저장 위치 묻기」를 켜 둔 이용자는 저장 창이 뜬다
- 자동 다운로드는 버튼을 누른 직후가 아니라 서버 응답을 받은 뒤 일어난다. 일부 브라우저는 이런 다운로드를 막거나 「여러 파일 다운로드 허용」을 묻는다. 그래서 「이미지로 저장」 버튼을 함께 둔다. 8번 문서의 실기기 점검에서 반드시 확인한다

### 코드 읽기

- `forwardRef`: 부모 컴포넌트가 이 카드의 실제 DOM 요소를 잡을 수 있게 한다. `html-to-image`는 DOM 요소를 받아 PNG를 만든다
- `bg-white`: 배경을 지정하지 않으면 PNG 배경이 투명해져 사진첩에서 까맣게 보일 수 있다
- `className="contents"`: `<div>`로 묶었지만 그리드 배치에서는 없는 것처럼 동작하게 한다
- 일반 `<img>`를 쓴 이유: `next/image`는 이미지를 늦게 불러오거나 주소를 바꿔 PNG 변환 시 빠질 수 있다. 같은 출처(`public/store/`)의 원본 파일을 바로 쓴다
- React 19에서는 `forwardRef` 없이 `ref`를 일반 props로 받을 수도 있다. 여기서는 동작이 분명한 `forwardRef`를 쓴다

### PNG 내려받기 함수

자동 다운로드와 버튼이 같은 함수를 쓴다.

`src/sections/credential-image/downloadCredentialPng.ts`

```ts
import { toPng } from 'html-to-image';

/**
 * DOM 요소를 PNG로 바꿔 내려받는다.
 * 저장 위치는 브라우저 기본 다운로드 폴더다. 웹에서는 폴더를 정할 수 없다.
 */
export async function downloadCredentialPng(node: HTMLElement, fileName: string): Promise<void> {
  // 글꼴이 다 불러와진 뒤에 변환한다. 아니면 PNG에 기본 글꼴이 들어간다
  await document.fonts.ready;

  const dataUrl = await toPng(node, {
    pixelRatio: 2,
    backgroundColor: '#ffffff',
    cacheBust: true,
  });

  const link = document.createElement('a');
  link.href = dataUrl;
  link.download = fileName;
  link.click();
}
```

### 섹션 컴포넌트

`src/sections/credential-image/CredentialImageSection.tsx`

```tsx
'use client';

import { useEffect, useRef, useState } from 'react';
import { SectionWrapper } from '@/components/SectionWrapper';
import { Button } from '@/components/ui/Button';
import { commonContent } from '@/content/common';
import { useFlow } from '@/features/flow/FlowProvider';
import type { SectionProps } from '../types';
import { CredentialCard } from './CredentialCard';
import { credentialImageContent as content } from './content';
import { downloadCredentialPng } from './downloadCredentialPng';

export function CredentialImageSection({ id }: SectionProps) {
  const { orgCode, account } = useFlow();
  const cardRef = useRef<HTMLDivElement>(null);
  const lastDownloadedAccountIdRef = useRef<string | null>(null);
  const [isSaving, setIsSaving] = useState(false);
  const [hasError, setHasError] = useState(false);

  /** 카드를 PNG로 내려받는다. 실패하면 오류 문구를 보여 준다 */
  async function saveImage() {
    const card = cardRef.current;
    if (!card) return;

    try {
      await downloadCredentialPng(card, content.fileName);
      setHasError(false);
    } catch {
      setHasError(true);
    }
  }

  // 계정이 발급·재발급되면 자동으로 한 번 내려받는다
  useEffect(() => {
    if (!account) return;
    if (lastDownloadedAccountIdRef.current === account.accountId) return;

    lastDownloadedAccountIdRef.current = account.accountId;
    void saveImage();
    // 계정이 바뀔 때만 실행한다
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [account]);

  // registry의 visibleWhen이 막지만, 타입상 한 번 더 확인한다
  if (!orgCode || !account) {
    return null;
  }

  async function handleSave() {
    if (isSaving) return;
    setIsSaving(true);
    await saveImage();
    setIsSaving(false);
  }

  return (
    <SectionWrapper id={id}>
      <CredentialCard ref={cardRef} orgCode={orgCode} account={account} />

      <Button onClick={handleSave} disabled={isSaving} className="mt-6">
        {isSaving ? content.savingButton : content.saveButton}
      </Button>

      <p aria-live="polite" className="mt-3 text-danger">
        {hasError ? commonContent.errors.network : ''}
      </p>
    </SectionWrapper>
  );
}
```

### 코드 읽기

**자동 다운로드**
- `useEffect(..., [account])`: 화면이 그려진 **뒤에** 실행된다. 그래서 `cardRef.current`에 카드 요소가 이미 들어 있다
- 계정이 처음 생기면(발급) 이 섹션이 나타나며 실행되고, 계정이 바뀌면(재발급) 다시 실행된다
- `lastDownloadedAccountIdRef`: 마지막으로 내려받은 아이디를 기억한다. 개발 모드에서 `useEffect`가 두 번 실행되거나 다른 이유로 다시 그려져도 같은 계정을 두 번 내려받지 않는다
- 자동 다운로드에서는 `isSaving`을 바꾸지 않는다. 버튼 잠금은 버튼을 눌렀을 때만 쓴다

**내려받기**
- `downloadCredentialPng`를 별도 파일로 뺐다. 자동 다운로드와 버튼이 같은 함수를 쓴다
- `toPng(node, { pixelRatio: 2 })`: 화면보다 2배 촘촘하게 만들어 사진첩에서 확대해도 선명하다
- `cacheBust: true`: 이미지가 캐시 때문에 빠지는 경우를 줄인다
- `link.download = fileName`, `link.click()`: 코드로 링크를 눌러 기본 다운로드 폴더에 내려받는다
- 재발급으로 같은 이름의 파일을 또 받으면 브라우저가 `weedool-account (1).png`처럼 이름을 바꿔 저장한다

**그 밖**
- 훅(`useFlow`, `useRef`, `useState`, `useEffect`)을 모두 부른 **뒤에** `return null`을 한다. 훅보다 먼저 `return`하면 「훅 호출 순서가 바뀌었다」는 오류가 난다
- `useRef<HTMLDivElement>(null)`: 카드 DOM 요소를 담을 상자. `ref={cardRef}`로 연결한다
- 저장하지 않아도 아래 섹션으로 스크롤할 수 있다. 이 섹션은 아무것도 막지 않는다

### 컴포넌트

`src/sections/install/InstallSection.tsx`

```tsx
import Image from 'next/image';
import { SectionWrapper } from '@/components/SectionWrapper';
import { ButtonLink } from '@/components/ui/Button';
import { links } from '@/config/links';
import type { SectionProps } from '../types';
import { installContent } from './content';

const stores = [
  {
    key: 'ios',
    href: links.appStore.href,
    qrImage: links.appStore.qrImage,
    buttonLabel: installContent.appStoreButton,
    qrAlt: installContent.iosQrAlt,
  },
  {
    key: 'android',
    href: links.googlePlay.href,
    qrImage: links.googlePlay.qrImage,
    buttonLabel: installContent.googlePlayButton,
    qrAlt: installContent.androidQrAlt,
  },
];

export function InstallSection({ id }: SectionProps) {
  return (
    <SectionWrapper id={id} title={installContent.title}>
      <div className="grid gap-6 sm:grid-cols-2">
        {stores.map((store) => (
          <div key={store.key} className="flex flex-col items-center gap-4 rounded-2xl bg-surface p-5">
            <Image src={store.qrImage} alt={store.qrAlt} width={160} height={160} />
            <ButtonLink href={store.href} target="_blank" rel="noopener noreferrer">
              {store.buttonLabel}
            </ButtonLink>
          </div>
        ))}
      </div>
    </SectionWrapper>
  );
}
```

### 코드 읽기

- 이 섹션은 상태를 쓰지 않아 `'use client'`가 없다
- `sm:grid-cols-2`: 640px 이상에서만 두 칸으로 나란히, 휴대전화에서는 위아래로 쌓는다
- `target="_blank"`: 스토어를 새 탭으로 연다. `rel="noopener noreferrer"`는 새 탭이 이 페이지를 조작하지 못하게 막는 보안 설정이다
- ⑤·⑥과 별도 섹션이라 계정 영역과 떨어져 보인다 (기획 문서 4장 ⑦)
