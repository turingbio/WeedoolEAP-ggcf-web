# 6. 섹션 시스템

목표: 랜딩 페이지를 **설정 배열 하나**로 조립한다. 섹션 순서 바꾸기, 끄기, 추가하기가 이 배열 수정만으로 끝나게 한다. 기획 문서 2장.

---

## 6-1. 구조

```
app/welcome/page.tsx
  └─ RequireOrgCode            (4번 문서, 기관코드 없으면 /verify)
      └─ LandingSections       (registry를 읽어 섹션을 차례로 그림)
          ├─ IntroSection      ─┐
          ├─ AnonymitySection   │ 각 섹션은 SectionWrapper로 감싸
          ├─ ManualSection      │ 간격·제목·anchor를 통일
          ├─ ...               ─┘
          └─ Footer
```

| 파일 | 역할 | 언제 고치나 |
| --- | --- | --- |
| `sections/registry.ts` | 섹션 순서·켜기·표시 조건 | 섹션 추가·삭제·순서 변경 |
| `sections/types.ts` | 모든 섹션이 받는 props 모양 | 거의 안 고침 |
| `sections/LandingSections.tsx` | registry대로 그리기 | 거의 안 고침 |
| `components/SectionWrapper.tsx` | 섹션 공통 틀 | 간격·제목 스타일 변경 |

---

## 6-2. 섹션 props 타입

모든 섹션 컴포넌트는 `id` 하나를 받는다. registry에 적은 id가 그대로 들어온다.

`src/sections/types.ts`

```ts
export type SectionProps = {
  /** registry의 id. HTML id(anchor)로 쓴다 */
  id: string;
};
```

④와 ⑧은 같은 매뉴얼 컴포넌트를 쓰지만 id가 달라(`manual-top`, `manual-bottom`) HTML id가 겹치지 않는다.

---

## 6-3. 공통 틀

`src/components/SectionWrapper.tsx`

```tsx
type SectionWrapperProps = {
  id: string;
  /** 섹션 제목. 없으면 제목 없이 그린다 */
  title?: string;
  children: React.ReactNode;
};

export function SectionWrapper({ id, title, children }: SectionWrapperProps) {
  const titleId = `${id}-title`;

  return (
    <section
      id={id}
      aria-labelledby={title ? titleId : undefined}
      className="mx-auto w-full max-w-xl scroll-mt-4 px-5 py-10"
    >
      {title && (
        <h2 id={titleId} className="mb-6 text-title font-bold">
          {title}
        </h2>
      )}
      {children}
    </section>
  );
}
```

### 코드 읽기

- `id={id}`: 주소 끝에 `#account`를 붙이면 그 섹션으로 스크롤된다
- `aria-labelledby`: 화면 낭독기가 섹션을 제목 이름으로 알려 준다
- `max-w-xl`: 넓은 화면에서도 글줄이 너무 길어지지 않게 한다
- `px-5 py-10`: 섹션 간격은 **여기서만** 정한다. 섹션 컴포넌트에서 바깥 여백을 따로 주지 않는다
- `{title && (...)}`: `title`이 있을 때만 제목을 그린다

## 6-4. 섹션 목록 (registry)

섹션 컴포넌트는 7번 문서에서 만든다. **지금은 임시 섹션**으로 틀부터 확인한다.

### 임시 섹션 만들기

섹션 폴더마다 같은 모양의 임시 파일을 만든다. 7번 문서에서 내용을 채운다.

`src/sections/intro/IntroSection.tsx`

```tsx
import { SectionWrapper } from '@/components/SectionWrapper';
import type { SectionProps } from '../types';

export function IntroSection({ id }: SectionProps) {
  return (
    <SectionWrapper id={id} title="intro (임시)">
      <p>임시</p>
    </SectionWrapper>
  );
}
```

같은 방식으로 아래 파일을 만든다. 함수 이름과 제목만 바꾼다.

| 파일 | 함수 이름 |
| --- | --- |
| `src/sections/anonymity/AnonymitySection.tsx` | `AnonymitySection` |
| `src/sections/manual/ManualSection.tsx` | `ManualSection` |
| `src/sections/account/AccountSection.tsx` | `AccountSection` |
| `src/sections/credential-image/CredentialImageSection.tsx` | `CredentialImageSection` |
| `src/sections/install/InstallSection.tsx` | `InstallSection` |

### registry

`src/sections/registry.ts`

```ts
import type { ComponentType } from 'react';
import type { FlowState } from '@/types/domain';
import { AccountSection } from './account/AccountSection';
import { AnonymitySection } from './anonymity/AnonymitySection';
import { CredentialImageSection } from './credential-image/CredentialImageSection';
import { InstallSection } from './install/InstallSection';
import { IntroSection } from './intro/IntroSection';
import { ManualSection } from './manual/ManualSection';
import type { SectionProps } from './types';

export type SectionDefinition = {
  /** HTML id(anchor). 페이지 안에서 겹치면 안 된다 */
  id: string;
  /** 그릴 섹션 컴포넌트 */
  Component: ComponentType<SectionProps>;
  /** false면 그리지 않는다 */
  enabled: boolean;
  /** 흐름 상태를 보고 보일지 정한다. 없으면 항상 보인다 */
  visibleWhen?: (state: FlowState) => boolean;
};

/**
 * 랜딩 페이지 섹션 목록. 위에서 아래 순서대로 그린다.
 * 순서 변경·끄기·추가는 이 배열만 고친다. (기획 문서 1장)
 */
export const landingSections: SectionDefinition[] = [
  { id: 'intro', Component: IntroSection, enabled: true },
  { id: 'anonymity', Component: AnonymitySection, enabled: true },
  { id: 'manual-top', Component: ManualSection, enabled: true },
  { id: 'account', Component: AccountSection, enabled: true },
  {
    id: 'credential-image',
    Component: CredentialImageSection,
    enabled: true,
    visibleWhen: (state) => state.account !== null,
  },
  { id: 'install', Component: InstallSection, enabled: true },
  { id: 'manual-bottom', Component: ManualSection, enabled: true },
];
```

### 코드 읽기

- `ComponentType<SectionProps>`: 「`id`를 받는 React 컴포넌트」라는 타입
- `Component`를 대문자로 시작한 이유: React는 대문자로 시작하는 이름만 컴포넌트로 그린다. `<Component />`로 쓰기 위해서다
- `visibleWhen`: ⑥ 계정 정보 저장은 계정이 있을 때만 보인다
- 섹션을 새로 만들면: 폴더와 컴포넌트를 만들고, 이 배열에 한 줄 추가한다

## 6-5. 섹션 그리기

`src/sections/LandingSections.tsx`

```tsx
'use client';

import { useFlow } from '@/features/flow/FlowProvider';
import { landingSections } from './registry';

export function LandingSections() {
  const { orgCode, account } = useFlow();
  const state = { orgCode, account };

  const visibleSections = landingSections.filter(
    (section) => section.enabled && (section.visibleWhen?.(state) ?? true),
  );

  return (
    <>
      {visibleSections.map(({ id, Component }) => (
        <Component key={id} id={id} />
      ))}
    </>
  );
}
```

### 코드 읽기

- `'use client'`: `useFlow`(Context)를 쓰기 때문에 필요하다
- `section.visibleWhen?.(state) ?? true`: `visibleWhen`이 없으면 `true`, 있으면 실행 결과
- `key={id}`: 목록을 그릴 때 React가 각 항목을 구분하는 값. 겹치면 안 된다
- 이 파일에는 「계정이 있으면 이 섹션을」 같은 분기가 없다. 모두 registry에 있다

## 6-6. 푸터

`src/components/Footer.tsx`

```tsx
import { commonContent } from '@/content/common';

export function Footer() {
  return (
    <footer className="mt-10 border-t border-line bg-surface px-5 py-8 text-center text-muted">
      <a href={commonContent.footer.telHref} className="inline-flex min-h-touch items-center underline">
        {commonContent.footer.text}
      </a>
    </footer>
  );
}
```

- `tel:` 링크: 휴대전화에서 누르면 전화 앱이 열린다

## 6-8. 확인

`/verify?GGCF26=A1B2C3`로 들어가 `/welcome`을 연다.

| # | 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 화면 보기 | intro, anonymity, manual, account, install, manual 순서의 임시 섹션과 푸터. credential-image는 안 보임(계정 없음) |
| 2 | registry에서 `anonymity`의 `enabled`를 `false` | anonymity만 사라짐 |
| 3 | registry에서 `install` 줄을 `intro` 위로 옮김 | install이 맨 위에 보임 |
