## 6. 5초 테스트

대상: 실제 기관 직원 3~5명, 휴대폰 화면

1. 01 Hero 화면만 5초 보여 주고 가립니다.
2. 묻습니다: "어떤 서비스 같아요?", "누가 보낸 것 같아요?", "다음에 뭘 하면 될까요?"
3. 03 익명성 섹션을 보여 준 뒤 묻습니다: "이 앱을 쓰면 회사가 알 것 같아요?"
4. 대답이 2장 표의 "답"과 다르면 그 섹션 제목을 다시 고릅니다.
