## 3. 착수 전에 고칠 것

1. `11_seed.yaml`, `PRODUCT.md`에서 재발급 흐름(만료 시 재발급 안내·버튼)을 뺍니다. "흐름 7단계, 매뉴얼 두 곳"을 21 v0.8 구성(매뉴얼 버튼은 install 한 곳)에 맞춥니다. impeccable이 `PRODUCT.md`를 읽으므로 가장 먼저 합니다.
2. `PRODUCT.md`의 "아직 없는 것" 목록을 고칩니다. 로고는 `42_디자인_자산/brand/`에 있습니다.
3. 섹션 id를 통일합니다. 문서는 `process`, 코드(`src/sections/registry.ts`, 폴더)는 `app-flow`입니다.
4. `40_디자인_토큰.yaml`을 `90_archive/`로 옮기고 `00_README.md`에서 뺍니다. 파일 머리말이 archive의 DESIGN*.md를 참조합니다.
5. 커밋되지 않은 docs 정리와 섹션 코드 수정을 먼저 커밋합니다.
