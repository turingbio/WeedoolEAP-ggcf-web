# 10. 점검과 마무리

목표: 9번 문서의 디자인이 들어간 화면을 반응형·접근성 기준으로 점검하고, 완료 기준을 통과시키고, 나중에 할 일을 정리한다.

---

## 10-1. 반응형 점검

### 기기 모드 켜는 법

1. Chrome에서 `F12`로 개발자 도구를 연다
2. `Ctrl + Shift + M` (또는 왼쪽 위 휴대전화 모양 아이콘)
3. 위쪽 너비 입력칸에 숫자를 넣는다

| 너비   | 기준                                          |
| ------ | --------------------------------------------- |
| 360px  | 가로 스크롤 없음, 글자·버튼 잘림 없음         |
| 390px  | 위와 같음                                     |
| 430px  | 위와 같음                                     |
| 768px  | ⑦ 앱 설치가 두 칸으로 나란히                  |
| 1280px | 콘텐츠가 가운데 좁은 폭(`max-w-xl`) 안에 있음 |

가로 스크롤이 생기면 개발자 도구 Console에서 아래를 실행해 넘치는 요소를 찾는다.

```js
[...document.querySelectorAll('*')].filter(
  (el) => el.scrollWidth > document.documentElement.clientWidth,
);
```

## 10-2. 접근성 점검

| 항목      | 방법                                                               | 기준                                                 |
| --------- | ------------------------------------------------------------------ | ---------------------------------------------------- |
| 글자 크기 | 요소 선택 → Computed 탭 `font-size`                                | 본문 16px, 버튼 20px 이상                            |
| 터치 영역 | 버튼 선택 → 크기 표시                                              | 높이 48px 이상                                       |
| 대비      | 개발자 도구 Lighthouse 탭 → Accessibility → Analyze                | 대비 관련 경고 없음                                  |
| 키보드    | 마우스 없이 `Tab`만으로 처음부터 끝까지                            | 모든 버튼·링크에 초점 테두리가 보이고 순서가 위→아래 |
| 오류 알림 | Windows 「내레이터」(`Ctrl + Win + Enter`) 켜고 틀린 기관코드 입력 | 오류 문구를 읽어 줌                                  |
| 글자 확대 | `Ctrl + +`로 200%                                                  | 겹치거나 잘리는 글자 없음                            |
| 언어      | Elements 탭 `<html lang="ko">`                                     | 있음                                                 |

Lighthouse 접근성 점수보다 **경고 목록**을 본다. 경고가 나오면 항목 이름을 알려 주면 함께 고친다.

## 10-3. 실기기 점검

개발 서버를 같은 와이파이의 휴대전화에서 연다.

```bash
pnpm dev -H 0.0.0.0
```

1. PC에서 `ipconfig`로 IPv4 주소를 찾는다 (예: `192.168.0.10`)
2. 휴대전화 브라우저에서 `http://192.168.0.10:3000/verify?GGCF26=GGCF26`
3. Windows 방화벽 허용 창이 뜨면 「개인 네트워크」를 허용한다

| 기기           | 확인                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| iPhone Safari  | 기관코드 자동 확인, 대문자 키보드, 계정 발급 시 PNG 자동 다운로드(파일 앱 → 다운로드), 「이미지로 저장」, PDF 저장, 전화 걸기 |
| Android Chrome | 위와 같음, PNG가 `Download` 폴더에 자동 저장                                                                                  |

자동 다운로드가 막히거나 「여러 파일 다운로드 허용」 창이 뜨면 기기·브라우저 이름과 함께 알려 준다. 막히는 기기가 많으면 방식을 다시 정한다.

## 10-4. 완료 시나리오

Seed 인수 기준과 기획 문서를 기준으로 한 최종 점검이다. 탭을 새로 열어 처음부터 진행한다.

| #   | 시나리오                     | 기대 결과                                                                                                        | 근거        |
| --- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------- | ----------- |
| 1   | `/verify?GGCF26=GGCF26` 접속 | 입력칸 자동 입력 → `/welcome`                                                                                    | AC1         |
| 2   | 틀린 기관코드                | 오류 문구, 수기 입력 가능                                                                                        | AC1         |
| 3   | `/`, 확인 전 `/welcome` 접속 | `/verify`로 이동                                                                                                 | 기획 1장    |
| 4   | 랜딩 페이지 새로고침         | `/welcome` 유지, 계정은 발급 전                                                                                  | 기획 1장    |
| 5   | 소개·익명성                  | 기획 4장 ②③ 문구 그대로                                                                                          | AC2         |
| 6   | 계정 받기                    | 아이디·비밀번호·만료 시각 문구                                                                                   | AC3         |
| 7   | 만료                         | 같은 화면에 만료 문구와 「계정 재발급」                                                                          | AC3         |
| 8   | 재발급                       | 새 계정, PNG 카드도 새 계정                                                                                      | AC3         |
| 9   | 계정 발급·재발급             | PNG가 기본 다운로드 폴더에 자동 저장. 앱 이름·기관코드·아이디·비밀번호·QR 두 개. 「이미지로 저장」으로 다시 받기 | AC4         |
| 10  | 저장하지 않고 스크롤         | ⑦·⑧까지 내려감                                                                                                   | AC4         |
| 11  | 앱 설치                      | 계정 영역과 분리, iOS·Android 각각                                                                               | AC5         |
| 12  | 매뉴얼 ④·⑧                   | 같은 PDF                                                                                                         | 기획 4장 ④⑧ |
| 13  | 개인정보                     | 어느 화면도 이름·연락처 등을 묻지 않음                                                                           | Seed 제약   |
| 14  | 섹션 확장성                  | registry 수정만으로 섹션 끄기·순서 변경                                                                          | Seed 제약   |
| 15  | 문구 분리                    | 아래 명령 결과에 컴포넌트 파일이 없음                                                                            | Seed 제약   |
| 16  | 빌드                         | `pnpm build`, `pnpm lint` 오류 없음                                                                              | —           |

15번 확인 명령 (Git Bash):

```bash
grep -rnP '[가-힣]' src --include='*.tsx' | grep -v '//' | grep -v '{/\*'
```

결과가 없거나 주석뿐이면 통과다. `content.ts`는 `.ts`라 검색 대상이 아니다.

모두 통과하면 커밋한다.

```bash
pnpm format
git add -A -- . ':!docs'
git commit -m "chore: 반응형·접근성 점검 반영"
```

## 10-5. 실제 서버 연결

서버가 준비되면 코드는 고치지 않고 환경 변수만 바꾼다.

```
NEXT_PUBLIC_USE_MOCK=false
NEXT_PUBLIC_API_BASE_URL=https://서버주소
```

1. 개발 서버를 껐다 켠다
2. 8-4 시나리오 1~9를 다시 한다
3. 개발자 도구 Network 탭에서 요청 주소가 `/api/org/verify`, `/api/accounts`인지, 본문이 `{ "orgCode": "..." }`인지 본다
4. 에러 코드 이름이 계약과 다르면 `src/lib/api/errors.ts`의 `INVALID_ORG_CODE_CODES` 배열만 고친다
5. 브라우저 Console에 CORS 오류가 나오면 백엔드에 웹사이트 도메인 허용을 요청한다

## 10-7. 자주 나는 오류

| 오류 메시지 (일부)                                           | 원인                                                                           | 해결                                                    |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------- |
| `You're importing a component that needs useState`           | 훅을 쓰는 파일에 `'use client'` 없음                                           | 파일 첫 줄에 `'use client';`                            |
| `useSearchParams() should be wrapped in a suspense boundary` | `Suspense`로 안 감쌈                                                           | 5-4처럼 `<Suspense>`로 감싼다                           |
| `useFlow는 FlowProvider 안에서만 쓸 수 있습니다`             | `layout.tsx`에 `FlowProvider` 없음                                             | 4-4 확인                                                |
| `Rendered more hooks than during the previous render`        | 훅보다 먼저 `return`                                                           | 훅을 모두 부른 뒤 `return`                              |
| `Hydration failed`                                           | 서버와 브라우저에서 그린 내용이 다름 (`Date.now()`, `window`를 렌더링 중 사용) | 해당 값을 `useSyncExternalStore`나 이벤트 안으로 옮긴다 |
| `Module not found: Can't resolve '@/...'`                    | 경로 오타, 파일 이름 대소문자                                                  | 파일 이름과 import 경로를 대소문자까지 맞춘다           |
| 환경 변수가 `undefined`                                      | `.env.local` 수정 후 재시작 안 함, 이름에 `NEXT_PUBLIC_` 없음                  | 개발 서버 재시작, 이름 확인                             |
| 이미지로 저장 시 QR이 빠짐                                   | 외부 주소 이미지 사용                                                          | `public/`에 파일을 두고 `/store/...` 경로로 쓴다        |
| ESLint `react-hooks/...` 경고                                | 훅 사용 규칙 위반                                                              | 경고 이름과 파일을 알려 주면 함께 고친다                |
