# 4. 흐름 상태와 라우팅

목표: 확인된 기관코드와 발급된 계정을 모든 화면이 함께 쓰게 하고, 주소별 이동 규칙을 만든다.

---

## 4-1. 무엇을 만드는가

| 파일                               | 역할                                      |
| ---------------------------------- | ----------------------------------------- |
| `features/flow/storage.ts`         | `sessionStorage`에 기관코드를 읽고 쓴다   |
| `features/flow/FlowProvider.tsx`   | 기관코드·계정을 모든 컴포넌트에 나눠 준다 |
| `features/flow/RequireOrgCode.tsx` | 기관코드가 없으면 `/verify`로 보낸다      |
| `app/page.tsx`                     | `/` → `/verify`                           |
| `app/welcome/page.tsx`             | 가드로 감싼다                             |

### 왜 Context를 쓰는가

기관코드 확인 화면에서 확정한 기관코드를, 랜딩 페이지의 계정 발급 섹션과 PNG 섹션이 써야 한다. 컴포넌트마다 값을 props로 넘기면 복잡해지므로, 맨 위(`layout.tsx`)에 **Provider**를 두고 필요한 컴포넌트가 `useFlow()`로 꺼내 쓴다.

### 왜 useSyncExternalStore를 쓰는가

`sessionStorage`는 React 밖에 있는 저장소다. 서버에서 화면을 먼저 만들 때는 `sessionStorage`가 없고, 브라우저에서는 있다. `useSyncExternalStore`는 이런 값을 **서버 값 / 브라우저 값**으로 나눠 안전하게 읽게 해 준다.

- 서버에서는 `undefined`(아직 모름)를 돌려준다
- 브라우저에서는 저장된 기관코드 또는 `null`(없음)을 돌려준다
- 그래서 `undefined`인 동안은 「아직 읽는 중」이라고 판단할 수 있다

## 4-2. 저장소

`src/features/flow/storage.ts`

```ts
const STORAGE_KEY = 'weedool:orgCode';

/** 값이 바뀌었을 때 알려 줄 함수 목록 */
const listeners = new Set<() => void>();

function notify() {
  listeners.forEach((listener) => listener());
}

/** React가 값 변화를 구독할 때 부른다. 구독을 끊는 함수를 돌려준다 */
export function subscribeOrgCode(listener: () => void): () => void {
  listeners.add(listener);
  return () => {
    listeners.delete(listener);
  };
}

/** 브라우저에서 현재 값. 저장된 기관코드 또는 null */
export function getOrgCodeSnapshot(): string | null | undefined {
  try {
    return window.sessionStorage.getItem(STORAGE_KEY);
  } catch {
    // 사생활 보호 모드 등에서 저장소 접근이 막히면 없는 것으로 본다
    return null;
  }
}

/** 서버에서 화면을 만들 때의 값. 서버는 저장소를 모르므로 undefined */
export function getOrgCodeServerSnapshot(): string | null | undefined {
  return undefined;
}

export function saveOrgCode(orgCode: string): void {
  try {
    window.sessionStorage.setItem(STORAGE_KEY, orgCode);
  } catch {
    // 저장이 막혀도 앱이 멈추지 않게 한다
  }
  notify();
}
```

### 코드 읽기

- `sessionStorage`는 탭을 닫으면 지워진다. 새로고침에는 남는다
- `try/catch`: 일부 브라우저 설정에서 저장소 접근이 에러를 던진다. 앱이 멈추지 않게 막는다
- `notify()`: 값을 저장한 뒤 구독 중인 React에 「바뀌었다」고 알린다. 이게 없으면 화면이 갱신되지 않는다

## 4-3. FlowProvider

`src/features/flow/FlowProvider.tsx`

```tsx
'use client';

import { createContext, useContext, useState, useSyncExternalStore } from 'react';
import type { Account } from '@/types/domain';
import {
  getOrgCodeServerSnapshot,
  getOrgCodeSnapshot,
  saveOrgCode,
  subscribeOrgCode,
} from './storage';

type FlowContextValue = {
  /** 확인된 기관코드. 없으면 null */
  orgCode: string | null;
  /** 발급된 계정. 없으면 null */
  account: Account | null;
  /** 브라우저 저장소를 다 읽었는지 */
  isHydrated: boolean;
  /** 기관코드 확인 성공 시 부른다 */
  confirmOrgCode: (orgCode: string) => void;
  /** 계정 발급·재발급 성공 시 부른다 */
  setAccount: (account: Account) => void;
};

const FlowContext = createContext<FlowContextValue | null>(null);

export function FlowProvider({ children }: { children: React.ReactNode }) {
  const storedOrgCode = useSyncExternalStore(
    subscribeOrgCode,
    getOrgCodeSnapshot,
    getOrgCodeServerSnapshot,
  );
  // 계정은 메모리에만 둔다. 새로고침하면 사라진다 (가이드 목차 「미리 정한 것」)
  const [account, setAccountState] = useState<Account | null>(null);

  const value: FlowContextValue = {
    orgCode: storedOrgCode ?? null,
    account,
    isHydrated: storedOrgCode !== undefined,
    confirmOrgCode: (orgCode) => {
      saveOrgCode(orgCode);
      setAccountState(null);
    },
    setAccount: (nextAccount) => setAccountState(nextAccount),
  };

  return <FlowContext.Provider value={value}>{children}</FlowContext.Provider>;
}

/** 흐름 상태를 꺼내 쓴다. FlowProvider 안에서만 쓸 수 있다 */
export function useFlow(): FlowContextValue {
  const value = useContext(FlowContext);
  if (!value) {
    throw new Error('useFlow는 FlowProvider 안에서만 쓸 수 있습니다');
  }
  return value;
}
```

### 코드 읽기

- `storedOrgCode ?? null`: `undefined`(서버)나 `null`(없음)이면 `null`로 통일한다
- `isHydrated`: `undefined`가 아니면 브라우저 값을 읽은 것이다
- `confirmOrgCode`: 새 기관코드를 확정하면 이전 계정은 비운다
- `useFlow`: Provider 밖에서 실수로 쓰면 바로 알 수 있게 에러를 던진다

## 4-4. layout에 Provider 넣기

`src/app/layout.tsx`에서 `<body>` 안을 `FlowProvider`로 감싼다.

```tsx
import type { Metadata } from 'next';
import { FlowProvider } from '@/features/flow/FlowProvider';
import './globals.css';

export const metadata: Metadata = {
  title: '위둘 EAP',
  description: '위둘 EAP 안내',
};

export default function RootLayout({ children }: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="ko">
      <body className="bg-white font-sans text-body text-ink antialiased">
        <FlowProvider>{children}</FlowProvider>
      </body>
    </html>
  );
}
```

- `layout.tsx`는 서버 컴포넌트지만 클라이언트 컴포넌트(`FlowProvider`)를 안에 넣을 수 있다
- `metadata`를 쓰려면 `layout.tsx`에 `'use client';`를 붙이면 안 된다

## 4-5. 루트 주소 `/`

`/`로 들어오면 `/verify`로 보낸다. 루트는 나중에 다른 페이지로 쓸 수 있게 이 동작만 둔다.

`src/app/page.tsx`

```tsx
import { redirect } from 'next/navigation';

// 루트는 나중에 다른 용도로 쓸 수 있다. 지금은 기관코드 확인 화면으로 보내기만 한다.
export default function RootPage() {
  redirect('/verify');
}
```

- `redirect`는 서버 컴포넌트에서 쓰는 이동 함수다. `'use client';`가 필요 없다

## 4-6. 가드

기관코드가 없으면 `/verify`로 보내고, 있으면 내용을 보여 준다.

`src/features/flow/RequireOrgCode.tsx`

```tsx
'use client';

import { useRouter } from 'next/navigation';
import { useEffect } from 'react';
import { useFlow } from './FlowProvider';

export function RequireOrgCode({ children }: { children: React.ReactNode }) {
  const { orgCode, isHydrated } = useFlow();
  const router = useRouter();

  useEffect(() => {
    if (isHydrated && !orgCode) {
      router.replace('/verify');
    }
  }, [isHydrated, orgCode, router]);

  // 저장소를 읽기 전이거나 기관코드가 없으면 아무것도 그리지 않는다
  if (!isHydrated || !orgCode) {
    return null;
  }

  return <>{children}</>;
}
```

### 코드 읽기

- `router.replace`: 이동하되 방문 기록을 남기지 않는다. 뒤로 가기를 눌러도 `/welcome`에 다시 오지 않는다
- 저장소를 읽기 전에는 `null`을 돌려준다. 이렇게 하지 않으면 확인하지 않은 이용자에게 랜딩 페이지가 **잠깐 보였다가** 사라진다
- `useEffect`의 배열 `[isHydrated, orgCode, router]`: 이 값들이 바뀔 때마다 안의 코드를 다시 실행한다

## 4-7. /welcome에 가드 적용

import { RequireOrgCode } from '@/features/flow/RequireOrgCode';

## 4-8. 확인용 임시 버튼

기관코드 확인 화면은 5번 문서에서 만든다. 지금은 가드만 확인하기 위해 `/verify`에 임시 버튼을 둔다.

`src/app/verify/page.tsx` (임시)

```tsx
'use client';

import { useRouter } from 'next/navigation';
import { useFlow } from '@/features/flow/FlowProvider';

export default function VerifyPage() {
  const { confirmOrgCode } = useFlow();
  const router = useRouter();

  return (
    <main className="p-4">
      <button
        onClick={() => {
          confirmOrgCode('GGCF26');
          router.replace('/welcome');
        }}
      >
        임시 확인
      </button>
    </main>
  );
}
```

**확인:**

| #   | 할 일                                       | 기대 결과                                              |
| --- | ------------------------------------------- | ------------------------------------------------------ |
| 1   | 새 탭에서 `http://localhost:3000/`          | `/verify`로 바뀐다                                     |
| 2   | 새 탭에서 `/welcome`                        | `/verify`로 바뀐다. 「welcome」이 잠깐도 보이지 않는다 |
| 3   | `/verify`에서 「임시 확인」                 | `/welcome`에 「welcome」이 보인다                      |
| 4   | 3 다음 새로고침(F5)                         | 「welcome」이 그대로 보인다                            |
| 5   | 탭을 닫고 새 탭에서 `/welcome`              | `/verify`로 바뀐다                                     |
| 6   | 개발자 도구 → Application → Session Storage | `weedool:orgCode`에 `GGCF26`                           |
