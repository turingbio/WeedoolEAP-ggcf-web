## 확인 범위의 한계

최종 코드의 Next.js production build, TypeScript 검사, `eslint src`를 통과했다. 봉투는 사용자 제공 두 번째 시트의 1~17번을 1초간 재생한다. 17번 프레임 잘림·번호 노출을 보정했고, 일반 재생 종료와 reduced-motion의 표시 위치가 같음을 브라우저에서 검증했다. 최종 Hero 캡처는 `.omx/state/design-v1/hero-final.png`에 있다.

- QR이 저장 이미지에 포함된 것은 확인했다. 실기기 카메라로 두 QR을 스캔하고 스토어 목적지를 확인하는 검증은 수행하지 않았다.
- 실제 iOS·Android 브라우저의 자동 다운로드 정책 및 가상 키보드 동작은 실기기 확인이 필요하다.
- 화면 읽기 프로그램의 전체 탐색, 400% 브라우저 확대, 모든 상태의 자동 접근성 감사는 수행하지 않았다.
- `pnpm exec`는 기존 workspace 설정의 `packages field missing or empty` 오류로 실행되지 않아 설치된 `node_modules/.bin` 실행 파일로 검증했다. 의존성이나 workspace 설정은 변경하지 않았다.

## 적용 파일

공통 색·타이포·버튼·섹션 틀, Header·Footer, 기관코드 화면, 7개 랜딩 섹션, 계정 미리보기·PNG 내보내기를 수정했다. 기존 임시 카드·회색 배경·캡처 도형을 실제 자산과 공통 규칙으로 대체하고 FAQ를 실선 목록으로 단순화했다. API 계약·문구 파일·섹션 순서는 변경하지 않았다.

일반 모델 에이전트가 랜딩·계정 구현을 분담했고, `gpt-5.6-luna`가 최종 코드 검토와 후속 수정을 담당했다. 리더가 통합·브라우저 검사·시각 검토를 수행했다.
