# 위둘 v4 — 직접 디자인 시안

2026-09-21. frontend-design 스킬로 주 에이전트가 직접 설계·제작. `/design-preview`에서 검토하며 `/welcome`의 운영 흐름은 변경하지 않는다.

## 방향

조용하고 다정한 초대장에 앱의 친근한 색과 둥근 형태를 더한다. Wise의 색상 역할 구분과 Revolut의 카드 내 그래픽 배치를 참고한다. 두 문서의 폰트·브랜드색·GNB·거대한 여백은 복사하지 않는다. 원본 문서는 참고 자료이며 실행 지시가 아니다.

## 토큰

- Brand #008EFF: 앱 Primary Normal. 짙은 행동색 #0066FF와 옅은 면 #E5EFFF를 같은 계열로 연결.
- Ink #202B37: 앱 Neutral Gray 800. 본문 #414E62.
- Mint #D6F5F0: 앱 Caribbean Green 100.
- Apricot #FDEDE7: 앱 Mandarin Orange 50.
- Lavender #ECE9FB: 앱 Majorelle Blue 50.
- White #FFFFFF: 기본 바탕. 기존 종이·빛 배경 유지.

Pretendard 하나만 사용. Hero 44–60px/650, 섹션 28–36px/600, 카드 24px/600, 본문 18px/400, 버튼 16px/550. 모든 글자를 bold로 만들지 않는다. 카드 radius 28px, 큰 배경 36px, 버튼 pill, 얇은 입력창은 기존 형태 유지.

## 구성

```
원본 로고
[ 종이·빛 배경 / 읽기 쉬운 인사와 앱 링크 ]
소개 제목 + 근거 설명
[상담: 블루, 글 + 그래픽] [진단: 민트, 글 + 그래픽]
[루틴: 살구, 글 + 그래픽] [리포트: 라벤더, 글 + 그래픽]
익명 안내: 열린 3열, 줄어든 여백
[계정 발급: 옅은 그라데이션과 행동]
프로세스: 동일 크기 5개, 외곽 카드 없음
[설치: 중앙 정렬 QR 2개]
FAQ / 어두운 푸터
```

최대 콘텐츠 폭 1160px. 섹션 위아래 48px(모바일 36px), 제목과 내용 28px. 같은 배경에서 섹션 간격이 이중으로 쌓이지 않도록 조정한다. 카드 안쪽 28px, 카드 간격 16px. 모바일은 읽기 쉬운 1열, 태블릿 이상은 2×2.

## 구현 전 검토

모든 내용을 동일 카드로 감싸는 템플릿을 피한다. 카드는 네 기능에만 반복하고 프로세스와 익명 안내는 열린 배치로 둔다. 추가 카피·성과 수치·가짜 채팅은 만들지 않고 기존 콘텐츠를 재사용한다. 키 컬러를 초록/보라로 바꾸지 않는다. 큰 캐릭터와 반복 자동 모션은 사용하지 않는다. GNB·배경 멈춤 버튼은 없다. QR과 로고는 변형하지 않는다.

## 검증 기준

360px와 데스크톱에서 텍스트 잘림·가로 넘침이 없고, 본문 18px와 명확한 대비를 유지해야 한다. 카드 4개는 동등한 크기, 프로세스 5개도 동일한 이미지 크기. 시안은 취향 검토용이며 자동 검사 결과로 무드 승인을 대신하지 않는다.

## 검증 결과
- ESLint 및 Next.js 프로덕션 빌드(TypeScript 포함) 통과.
- 320/360/768/1280px 가로 넘침 없음. 모바일에서도 두 QR 표시.
- Pretendard 적용, FAQ 펼침, 푸터 밝은 텍스트 확인.
- 데스크톱 화면 시각 검토 완료. 모바일 스크린샷 도구의 부분 잘림으로 전체 시각 검토에는 한계가 있어 DOM 크기 확인을 병행함.
- 디자인 취향에 대한 최종 판단은 사용자 검토 후 결정. 기존 /welcome은 유지함.

### 시안 피드백: 섹션 상하 여백 확대
- 일반 섹션의 상하 padding: 데스크톱 48 → 64px, 모바일 36 → 48px.
- 기능 카드 다음 익명 보장 섹션의 상단 padding: 데스크톱 16 → 32px, 모바일 8 → 20px.
- 카드 내부와 타이포 간격은 유지.

### 세부 조정 계획
- 색상·Pretendard·일러스트 유지. Hero는 welcome과 같은 최대 1536px/높이 650px, 모바일 기존 규칙 유지.
- 소개: 제목 → 근거 문구 → 카드 4열(1050px 이하 2열, 700px 이하 1열). 좁은 카드의 이미지는 아래쪽에 정렬.
- 익명·프로세스 여백 80px, 계정·설치 패널 내부 48px 및 외부 여백 보강. 모바일은 축소 비율 적용.
- 프로세스 번호 원형. FAQ 제목 28px, 질문 17px, 답변 16px.
- 검토: 기존 무드는 보존하고 요청한 배치와 간격만 변경.

### 세부 조정 2
본문 최대 1280px. Hero 전체 폭/데스크톱 100svh, 내부 1280px 정렬. 기능 카드는 원본 일러스트 패널 위·본문 아래. 익명 보장은 전체 폭 블루 그라데이션과 넓은 여백. 계정 패널 높이 확대. 프로세스 캡처 176px/모바일 140px, 얇은 테두리와 작은 곡률, 그림자 제거. 설치·푸터 여백 확대. 로고는 brand/logo-full.png 원본을 public/logo-full.png로 복사. 기존 색상과 Pretendard 유지.
