2. 타이포

토큰 정의는 src/app/typography.css에 있습니다. 그 파일은 Tailwind의 @theme 블록이라 브라우저가 직접 읽지 못하므로, 이 페이지는 같은 값을 다시 적어 그립니다. 값이 바뀌면 두 곳을 함께 고칩니다.

본문 최솟값은 16px입니다. 14px은 제목 위 라벨, Footer 사업자 정보, 캡션에만 쓰고 13px 이하는 쓰지 않습니다.

4. 컴포넌트

버튼

높이 48px 이상, 글자 20px 600, 반경 full. 누르는 동안 크기와 위치를 바꾸지 않고 색만 바뀝니다. 진행 중에는 스피너 대신 문구를 바꿉니다.

입력칸 (기관코드)

기관코드를 다시 확인해 주세요

경계선은 불투명한 --cool-neutral-80을 씁니다. 반투명 --line-normal은 흰 바탕에서 약 1.32:1이라 입력칸을 알아보는 유일한 단서로 쓸 수 없습니다. placeholder는 두지 않고, 오류 문구 자리는 평소에도 비워 둡니다.

FAQ

소속 기관에서 제가 이용하는 사실을 알 수 있나요?▸

알 수 없습니다. 기관은 누가 이용하는지 모르며, 상담 대화와 자가진단 결과도 볼 수 없습니다.

상담이나 진단 결과가 인사평가에 반영되나요?▸

반영되지 않습니다. 기관은 상담 내용을 볼 수 없고, 상담 데이터는 이용자를 평가하거나 선별하는 근거로 쓰이지 않습니다.

6. 접근성

아래 대비는 이 페이지에서 계산한 값입니다. WCAG 2.1 AA(본문 4.5:1, 큰 글자 3:1)가 기준입니다.

조합 견본 대비 판정

이 표는 색 조합만 봅니다. 화면 전체의 적합성은 실제 화면에서 포커스·오류·확대 상태까지 확인해야 합니다.

7. 하지 않는 것

  • 그림자로 깊이를 만들지 않는다
  • 그라디언트를 면에 쓰지 않는다 (/verify 배경은 예외)
  • 앱 팔레트 밖의 색을 만들지 않는다
  • 느낌표와 과장 표현을 쓰지 않는다
  • 동작 원리를 설명하는 문구를 넣지 않는다
  • 아이콘 세트를 새로 들이지 않는다
