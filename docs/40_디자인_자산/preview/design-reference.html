Runway 분석

docs/40_디자인_자산/DESIGN-reference.md의 토큰을 그대로 렌더링한 페이지입니다. 위둘에 그대로 적용하는 값이 아니라, 무엇을 가져오고 무엇을 두고 왔는지 비교하려고 만든 지면입니다. 위둘 정본은 디자인 시스템 확인 페이지에 있습니다.

색 타이포 형태 컴포넌트 위둘과의 차이

원본 서체는 abcNormal 독점 폰트라 이 페이지에서 쓸 수 없습니다. 시스템 산세리프로 대체해 그렸으므로 자소 모양은 원본과 다릅니다. 크기·굵기·행간·자간은 문서 값 그대로입니다.

색

검정과 흰색이 축이고, 회색 사다리가 촘촘합니다. 신호색(빨강·초록·노랑)이 없습니다. 폼의 검증 상태도 색이 아니라 테두리와 문장으로 알립니다.

타이포

한 벌의 산세리프가 모든 층위를 맡습니다. 제목은 굵기를 올리지 않고 크기와 음수 자간으로만 위계를 만듭니다. 제목 행간이 1.0이라 여러 줄이 되면 촘촘하게 붙습니다.

간격

깊이

그림자를 전혀 쓰지 않습니다. 깊이는 사진을 겹치거나 면 색을 한 단계 바꾸는 방식으로만 만듭니다.

단계 처리 쓰는 곳
평면 그림자 없음, 1px hairline 구분선 카드, 가격표, 목록, Footer
사진 scrim 위에 사진을 꽉 채움, 담긴 형태는 16px 반경 Hero, 중간 삽입 구간
면 단차 흰 면 위에 hairline 면을 얹음 강조 요금제 한 칸

컴포넌트

버튼

높이 40px, 글자 14px 600, 반경 full. 검정 알약이 모든 주 동작을 맡고 강조색이 따로 없습니다.

입력칸

박스가 아니라 아래쪽 1px 실선 한 줄입니다. 반경 0, placeholder는 stone 회색입니다.

무제한 생성

카드를 띄우지 않고 한 덩어리를 세로선으로 나눕니다. 강조 칸에 배지나 테두리를 두르지 않고 바탕색만 한 단계 올립니다.

위둘과의 차이

DESIGN.md 1-3에서 정한 내용입니다. 가져온 것은 지면을 짜는 방식이고, 가져오지 않은 것은 색과 글자 크기입니다.

가져온 것

  • 넓은 여백과 섹션 리듬 64/96px
  • 제목과 본문의 위계
  • 얇은 실선 구분, 그림자 없는 면
  • 일관된 알약형 버튼
  • 8px 기준 간격 사다리

가져오지 않은 것

  • 흑백 중심 색. 위둘은 앱 팔레트의 파랑을 쓴다
  • 영화 같은 사진. 위둘은 실제 앱 화면과 편지봉투를 쓴다
  • 14px 버튼 글자. 위둘은 20px에 높이 48px
  • 밑줄 한 줄 입력칸. 위둘은 박스에 2px 경계선
  • 반경 0 카드. 위둘은 16px
