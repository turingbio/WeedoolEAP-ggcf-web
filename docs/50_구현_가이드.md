## 미리 정한 것

| 항목                    | 결정                                 | 이유                                                                    |
| ----------------------- | ------------------------------------ | ----------------------------------------------------------------------- |
| 패키지 매니저           | pnpm                                 | 이미 설치되어 있고 설치가 빠르다                                        |
| 기관코드 확인 상태 저장 | `sessionStorage`                     | 새로고침에는 유지되고, 탭을 닫으면 지워진다                             |
| 아이디·비밀번호         | 브라우저에 저장하지 않는다           | 개인정보 흔적을 남기지 않는다. 새로고침으로 사라져도 재발급 제한이 없다 |
| 계정 정보 PNG           | `html-to-image` 라이브러리           | PNG 디자인을 일반 컴포넌트처럼 만들고 고칠 수 있다                      |
| 서버                    | 만들지 않는다. mock 함수로 흉내 낸다 | Seed 범위                                                               |
