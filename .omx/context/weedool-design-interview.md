# 위둘 디자인 취향 인터뷰

## 현재 요청
충분한 인터뷰를 통해 사용자 취향을 파악하고 DESIGN.md를 고도화한다. 인터뷰 중 사이트 코드는 수정하지 않는다. 문서 합의 전에 다음 디자인을 구현하지 않는다.

## 확정된 사용자 피드백
- 위둘 컨셉은 숲이 아니다.
- 노인만을 위한 사이트가 아니다. 접근성을 이유로 모든 요소를 굵게 만드는 v1 표현은 거부한다.
- 현재 봉투 이미지 애니메이션은 품질이 낮아 다음 디자인에서 제외한다. 편지라는 개념 전체를 거부한 것으로 확대 해석하지 않는다.
- v2는 v1보다 시각적으로 낫지만 위둘 브랜드에 맞는 결과는 아니다.
- 이전에 선택한 조용하고 다정한 초대장이라는 무드는 구체적 취향 확인을 통해 재해석해야 한다.

## 참고
DESIGN.md (v2), docs/40_디자인_자산/DESIGN-reference.md, docs/90_archive/DESIGN-v1-20260918.md. 앞선 대화에서 구현 및 비교 완료. 추가 코드 탐색 불필요.

## 인터뷰 방향
좋아하는 실제 예와 이유 → 싫어하는 표현과 경계 → 위둘의 성격 → 색/타이포/이미지/레이아웃/모션의 구체적 선호 → 충돌하는 선택 재확인 → 문서 반영.
한 번에 한 핵심 질문. 선호를 추천 선택지로 유도하지 않는다. 답변과 추론을 구분한다. 자체 점수로 취향 적합성이나 승인을 대체하지 않는다.

## 실행 환경
Codex App. OMX CLI 질문 런타임을 시작하지 않고 대화 인터뷰 원칙을 적용한다.

## 사용자 피드백 — 2차
### v1에서 거부한 표현
- 입력창의 이중으로 보이는 테두리와 강한 테두리 색.
- 크기·두께·색상으로 구분되지 않고 일괄적으로 bold한 타이포.
- 진한 색, 크고 두꺼운 글씨가 겹쳐 과하게 강조되는 버튼.
- 이미지·일러스트·아이콘의 활용 부족.
- 위둘 blue 편중, blue 명도 변화 부족, 팔레트의 다른 색상 고려 부족.
### v2에서 유지하고 싶은 장점
- 크기·두께·색상으로 명확히 드러나는 텍스트 위계.
- 압도적인 Hero 배경이 주는 강한 인상과 몰입.
- 흰 바탕과 아주 옅은 구분선.
- 여러 모노톤의 조화, 배경과 어울리는 절제된 컴포넌트.
### 개선 후보
- 앱 캡처를 원본 폰 비율 직사각형으로 나열하는 표현은 세련미 부족. 폰 목업 등 연출은 후속 디자인에서 검토.
### 취향 레퍼런스
- 산타토익 랜딩: 유사색상 배치의 조화, 뛰어난 정보 전달성, UX 라이팅.
- UX 라이팅 단계에서 이미 벤치마킹함. 이번 인터뷰는 디자인 취향 중심.
### 아직 확인이 필요한 해석
- 모노톤 자체를 원한다기보다 절제된 바탕 위 조화로운 색상과 시각적 풍부함을 원하는 것으로 추정. 확정 아님.
- Hero 몰입을 만드는 소재 선호: 일러스트/브랜드 캐릭터/제품 목업/추상 그래픽 등 미확정.

## 인터뷰 수렴 — 후속 답변 반영
확정 사항을 DESIGN.md 디자인 v3 인터뷰 반영안으로 통합했다. 현 사이트는 변경하지 않았다.
- 초대장 컨셉 유지, 첫 Hero A를 분위기 기준으로 선택.
- 주요 색은 블루 유지, 밝기 확장과 미색·따뜻한 파스텔 조화.
- 캐릭터 작게 제한. 그래픽은 분위기/설명 양쪽 역할.
- 기능 소개 4×1 또는 2×2, AI 상담은 폰 밖 말풍선 연출.
- 잔잔한 지속 모션 선호.
- 섹션 상하 여백 유지, 내부 요소 간격 확대.
- 크기 축소 대상은 프로세스 이미지와 QR. 글자 일괄 축소 아님.
- 다섯 단계 이미지 유지·동일 크기로 축소. 각 칸 border 제거.
- QR은 모든 뷰포트에서 표시.
- 기관코드는 첨부한 연결된 6칸 OTP형 외관. 둥근 단일 외곽선, 얇은 내부선.
문서는 검토안이며 구현 승인을 의미하지 않는다.
